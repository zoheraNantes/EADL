# Chapitre 08 — Outils et frameworks

## 1. Différence entre outil et framework

**Outil :** logiciel utilisé pour accomplir une tâche.

**Framework :** cadre logiciel fournissant des composants et des conventions pour développer ou tester.

## 2. Outils CI/CD

### GitHub Actions

Automatisation des workflows et pipelines GitHub.

### GitLab CI/CD

Automatisation des pipelines GitLab.

### Jenkins

Serveur d'automatisation extensible avec des plugins.

### Azure DevOps

Plateforme Microsoft proposant notamment des pipelines, la gestion du code et des tests.

## 3. Frameworks de tests

### pytest

- Langage : Python.
    
- Tests unitaires, d'intégration et API.
    
- Concepts : fixtures, paramétrage, assertions, plugins.
    

### JUnit 5

- Langages : Java et Kotlin.
    
- Tests unitaires et d'intégration.
    
- Framework de référence dans l'écosystème Java.
    

### Selenium

- Automatisation des navigateurs.
    
- Tests E2E.
    
- Utilise WebDriver.
    

### Cypress

- Tests E2E des applications Web.
    
- JavaScript et TypeScript.
    

### Playwright

- Tests E2E des applications Web.
    
- Plusieurs langages et navigateurs.
    
- Attentes automatiques et traces de tests.
    

## 4. Outils de qualité

### Ruff

Analyse statique et formatage du code Python.

### ESLint

Analyse statique du code JavaScript et TypeScript.

### coverage.py

Mesure la couverture des tests Python.

### JaCoCo

Mesure la couverture des tests Java.

## 5. Outils de sécurité

### pip-audit

Recherche les vulnérabilités connues dans les dépendances Python.

### Trivy

Analyse notamment les images de conteneurs et leurs vulnérabilités.

### Snyk

Analyse des vulnérabilités dans les dépendances et d'autres composants logiciels.

## 6. Outils de performance

### Locust

Tests de charge et de performance, avec des scénarios Python.

### JMeter

Tests de charge et de performance.

## 7. Outils de conteneurisation

### Docker

Exécution d'applications dans des conteneurs.

### Docker Compose

Gestion de plusieurs conteneurs pour une application.

### Kubernetes

Orchestration de conteneurs.

## À retenir

- **pytest / JUnit** = tests unitaires et d'intégration.
    
- **Selenium / Cypress / Playwright** = tests navigateur.
    
- **Ruff / ESLint** = qualité du code.
    
- **coverage.py / JaCoCo** = couverture.
    
- **GitHub Actions / GitLab CI / Jenkins** = pipelines.
    
- **Locust / JMeter** = performance.
    
- **Docker / Kubernetes** = conteneurs.
